# Herramientas del equipo

Herramientas que usaremos durante el proyecto y para qué sirve cada una.

| Herramienta | Para qué la usaremos |
| --- | --- |
| Git | Guardar el historial de cambios del proyecto y trabajar cada tarea en su propia rama. |
| GitHub | Alojar el repositorio del equipo, revisar el trabajo de cada integrante con Pull Requests y registrar pendientes en Issues. |
| VS Code | Editar los documentos en Markdown y el código de la plataforma, con la terminal integrada para usar Git. |
| Figma | Diseñar los prototipos de la interfaz en la etapa de UI. Los enlaces y exportaciones se guardan en docs/ui. |
| Python | Programar la plataforma de analítica y procesar los datos del cliente. |
| Markdown | Documentar los entregables de UX y UI dentro del repositorio, en archivos .md. |
